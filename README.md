# Avora — Focus your time. Find your balance.

A minimalist mindfulness and productivity sanctuary featuring Pomodoro timers, Eisenhower Matrix task management, reflective journaling, ambient soundscapes, and guided breathing exercises.

---

## 🚀 How to Run in VS Code

### 1. Place Your 6 Images in the `public` Folder
In your project folder, create a folder named `public` (if not already created) and place your 6 PNG images inside:

```text
AVORA/
├── public/
│   ├── AvoraLogo.png
│   ├── BreathingFaceIcon.png
│   ├── JournalPenIcon.png
│   ├── PomodoroClockIcon.png
│   ├── RelaxingSoundIcon.png
│   └── TaskCalendarIcon.png
├── src/
├── package.json
└── vite.config.ts
```

> **Why the `public/` folder?**  
> In Vite, any file placed inside `public/` is served directly to the browser at `/AvoraLogo.png`, `/PomodoroClockIcon.png`, etc.

---

### 2. Install Dependencies
Open your terminal in VS Code (`Ctrl + \`` or `Cmd + \``) and run:

```bash
npm install
```

---

### 3. Start the Development Server
Run:

```bash
npm run dev
```

Open your browser to `http://localhost:3000` to view Avora!

---

## ✨ Features Included
- **Avora Logo & Brand Identity:** Dark & Light mode support with local storage persistence.
- **1st Grid — Pomodoro Timer:** 5m, 15m, 25m presets and custom sliders, singing bowl completion chime, and completed sprint tracking.
- **2nd Grid — The Four Quadrants:** Eisenhower matrix with start & due dates/times, sort by due date, search, and completed tasks archive.
- **3rd Grid — Journal & Gratitude:** 8 daily moods with dynamic inspiring quotes and a dedicated "5 Things I'm Grateful For" list.
- **4th Grid — Relaxing Sound Sanctuary:** Gentle Web Audio soundscapes (Rain, Ocean, Campfire, Birds, Mountain Stream, and Tibetan singing bowl) with individual volume controls and sleep timer.
- **5th Grid — Guided Breathwork:** Visual pulsing circle with Box breathing (4-4-4-4), 4-7-8 relaxation, and Coherent 5-5 rhythms.
- **6th Grid — Patterns & Analytics:** Cognitive energy distribution across quadrants, sprint hours, and mood sentiment frequency.
- **6-Digit PIN Authentication:** Built-in demo account (`demo` / `123456`) and multi-account local persistence.
