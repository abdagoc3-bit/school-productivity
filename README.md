## Project Description
Avora is a minimalist productivity web application featuring tools like Pomodoro timers, an Eisenhower Matrix task manager, reflective journaling, ambient soundscapes, and guided breathing exercises to help users manage time and reduce stress.

---

## Main Features
- **Pomodoro Timer:** Customizable sprints with completion chimes.
- **Eisenhower Matrix:** Task management categorized into four quadrants with due dates.
- **Journal & Gratitude:** Daily mood tracking and 5 things to be grateful for.
- **Relaxing Sound Sanctuary:** Ambient Web Audio soundscapes (Rain, Ocean, Birds, etc.).
- **Guided Breathwork:** Visual pulsing circle for relaxation breathing.
- **Analytics & Auth:** Cognitive energy distribution and secure 6-digit PIN login.
